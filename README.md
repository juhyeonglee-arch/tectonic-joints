# tectonic-joints · 결구 생성기

나무 부재가 만나는 자리의 **결구(짜임)** 를 만들고, 검사하고, 레이저로 잘라 실물로 시험할 수 있게 내보내는 연구용 프로그램입니다. 한옥 결구에서 시작했지만 한옥에 한정하지 않고, 결구가 디자인으로 **드러나는지 숨는지**도 함께 다룹니다.

## 무엇을 하나

| 단계 | 하는 일 | 결과 |
|---|---|---|
| M1 전통 결구 | 장부·주먹장·반턱·메뚜기장 등 9가지 전통 결구를 만들고, 어느 방향으로 빠지는지·얇은 살·짧은 결을 검사 | 검사 그림, 결구별 그림, 라이노 `.3dm`(조립/분해), `검사결과.json` |
| M2 생성기 | 층별 요소(장부·주먹장·턱·없음)를 조합해 새 결구를 진화 탐색. 90°·60°·45° 조건 | 후보 그림, `.3dm`, `후보목록.json` |
| 세 부재 모서리 | 다리 + 장선 2개가 만나는 노드. 조립 순서와 열쇠 부재를 찾고 **드러냄/숨김** 목표로 후보를 고름 | 후보 그림, `.3dm` |
| M3 레이저 적층 | 노드를 판 두께로 썰어 판마다 DXF로. 커프·공차 보정, 정렬 핀 구멍, 판 번호 각인, 작업대 배치 | 판 DXF, 배치 미리보기, 판목록.csv, 조립순서도.png, 적층확인.3dm |

## 쓰는 법

### 웹에서 (설치 없음)
웹앱은 준비 중입니다. 완성되면 이 자리에 링크를 둡니다. 링크를 열고 판 두께·커프·공차·핀 지름·작업대 크기를 넣으면 DXF 묶음과 조립순서도를 바로 받을 수 있게 할 예정입니다.

### 레이저로 자를 때
1. M3 결과의 `공차시험편/공차시험편.dxf`를 먼저 잘라 실제 커프·공차·핀 구멍을 정합니다.
2. 값이 기본 가정(3mm MDF, 커프 0.2, 공차 0.2, 핀 4mm, 작업대 600×400)과 다르면 그 값으로 다시 뽑습니다.
3. `1대2_시험`부터 잘라 끼워 보고, 그다음 `1대1`.
4. 자세한 순서와 DXF 레이어(ENGRAVE / CUT_INNER / CUT_OUTER)는 [docs/M3_작업지시.md](docs/M3_작업지시.md)에 있습니다. 커프 보정이 이미 선에 들어가 있으니 레이저 프로그램에서 오프셋을 또 주지 마세요.

### 최신 결과 그림 받기
커밋마다 GitHub Actions가 Windows와 Linux에서 시험을 돌리고, 모든 결과(그림·DXF·3dm)를 산출물로 남깁니다.
**Actions 탭 → 최근 실행 → 아래쪽 Artifacts → `시험결과-ubuntu-latest`** 를 내려받으면 됩니다. 한눈에 보는 그림은 그 안의 `확인그림.png`입니다.

### 직접 돌릴 때 (개발용)
```
pip install -r requirements.txt
python src/run_m1.py 출력폴더
python src/run_node3.py 출력폴더                  # N3_CACHE=examples/node3_후보목록.json 이면 탐색 생략
python src/run_m2.py 출력폴더                     # 약 4분. M2_CACHE=examples/m2_후보목록.json 이면 그림만
python src/run_m3.py 출력폴더 examples/node3_후보목록.json
```
M3 값 바꾸기(환경변수): `M3_T`(판 두께) `M3_KERF` `M3_CLEAR`(맞춤 공차) `M3_PIN`(핀 지름) `M3_BED=600x400` `M3_SCALES=1,0.5`

## 자동 시험

`.github/workflows/test.yml` — 커밋·PR마다 Windows와 Linux에서:
- 설치 → M1·세 부재 모서리·M2(저장된 후보)·M3 실행
- 검사 결과 9개, 그림 크기, `.3dm`이 열리는지
- DXF 레이어가 3가지뿐인지, 모든 선이 작업대 안에 있는지, 판목록과 DXF 파일이 맞는지, 작업대 수(기본값에서 드러냄 11판·숨김 15판·1대2 각 2판)
- 판 두께에 맞춰 층을 옮긴 뒤에도 잠김(빠지는 방향)이 그대로인지 — 3.0·2.8·3.2mm, 그리고 바꾼 값(2.7mm, 커프 0.15, 작업대 500×300)
- 매일 한 번은 M2 진화 탐색 전체(약 4분)까지

**알려진 문제**: 숨김 노드는 판 두께 2.7·2.9·4mm에서 장선 X가 +x로 빠지게 됩니다. 시험에 "알려진 실패"로 표시해 두었고, 고치면 시험이 알려 줍니다.

## 저장소 구조
```
src/joinery/        코드 (grid, library, check, generator, geom, node3, assembly, laser, render, export3dm …)
src/joinery/fonts/  Pretendard (SIL OFL, 재배포 허용)
src/run_*.py        단계별 실행
examples/           예제 입력 (저장된 후보 목록)
tests/              자동 시험
tools/              확인 그림 모음 등
docs/               인계 문서, 연구노트, M3 작업지시
```

## 올리지 않는 것
- 개인 도면 파일, 재배포가 금지된 자료, 출처가 불확실한 참고 사진은 저장소에 넣지 않습니다. 필요하면 각자 자기 파일을 지정해서 씁니다(`private/`는 무시 목록에 있음).
- API 인증키는 쓰지 않습니다. 앞으로 필요해지면 GitHub Secrets나 사용자 입력으로 받습니다.
