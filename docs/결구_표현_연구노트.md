# 결구가 디자인으로 드러나는 방식 — 연구 노트 (2026-11-17)

범위: 한옥에 한정하지 않고 가구·현대 목구조·혼합(목재+금속) 접합까지. 참고 사진(refs_20261117/01~07.png)은 출처 확인 전이라 이 저장소에 넣지 않았다.

## 사진별 읽기
| 번호 | 무엇 | 결구가 드러나는 방식 |
|---|---|---|
| 01 | 상판 모서리에 둥근 장부 끝 4개가 꽃 모양으로 보이는 탁자 | 관통 장부의 **끝면(마구리)을 표면 무늬로** 남김. 파란 상판과 나무 결의 대비 |
| 02 | 다리 + 두 장선이 만나는 모서리, 두 가지 나무색 | **재료 색 대비**로 어느 부재가 어디를 감싸는지 읽힘. 다리 위로 솟은 장부 덩어리가 '매듭'처럼 보임 |
| 03 | 다리에 쐐기형 나무 손잡이 + 황동 막대, 상판 아래 오목한 받침 | **잠그는 장치(키·쐐기·핀)를 하나의 사물로** 디자인. 분해 가능함을 드러냄. 힘이 모이는 곳이 볼록하게 깎임 |
| 04 | 여러 부재가 비스듬히 엇갈려 바람개비처럼 겹친 노드 | **여러 부재 노드의 기하** 자체가 구성의 중심. 서로 기대는(상호 지지) 배치 |
| 05 | 세 각재가 비스듬히 서로 관통하는 교차 | **부재가 끊기지 않고 지나가는** 듯 보이게, 따낸 자리를 최소로 |
| 06 | 쪼갠 두 기둥 사이 틈 + 십자 강판 + 인장 로드 | **부재 다발과 틈**, 금속 접합판을 숨기지 않음, 힘의 종류(압축 나무 / 인장 강봉)가 재료로 갈림 |
| 07 | 네 갈래 기둥 사이로 보가 층을 달리해 지나가고 끝이 내밀어짐 | **관통과 내밀기**, 높이를 달리한 층 쌓기, 볼트·고리 같은 철물 노출 |

## 표현의 축 (생성기에 넣을 '표현 변수')
1. **드러냄 ↔ 숨김**: 맞물림이 겉에서 보이는가 (01 드러냄, M2의 '숨은 주먹장'은 숨김)
2. **재료 대비**: 부재마다·층마다 다른 재료/색 (02, 03, 06). 레이저 적층에서는 MDF·합판·색 아크릴을 층별로 바꿔 쌓는 것으로 바로 실험 가능
3. **잠금 장치의 사물화**: 쐐기·키·핀을 제3의 부재로 두고 모양을 디자인 (03, 한옥 산지·촉)
4. **부재 다발과 틈**: 한 부재를 2~4개로 쪼개 틈으로 다른 부재를 지나가게 (06, 07, 01의 다리)
5. **관통과 내밀기**: 부재가 노드를 지나 밖으로 얼마나 내미는가 (07, 05, 한옥 출목·보머리)
6. **다부재 노드 기하**: 세 부재 이상, 비스듬한 각도, 바람개비·상호 지지 (04, 05)
7. **힘의 흐름이 형태로**: 하중이 모이는 곳을 두껍게·볼록하게 (03)

## 생성기에 반영할 것
- 요소 어휘 확장: 장부·주먹장·턱 + 관통 장부(끝면 노출), 둥근 촉 다발, 쐐기/키(제3부재), 따냄 교차(반턱의 비스듬한 판), 쪼갠 부재(틈), 금속판(비목재 부재)
- 두 부재 → 여러 부재 노드: 각 부재 쌍의 빠짐 검사 + **조립 순서 찾기**(어떤 순서로 끼워야 하고 마지막 부재가 무엇을 잠그는가)
- 점수에 구조 기준과 함께 **표현 목표**를 넣음: 윗면에 드러나는 무늬, 재료 대비 경계 길이, 틈 폭, 내민 길이 등. 같은 구조 조건에서 표현 목표만 바꿔 다른 결구가 나오는지가 연구의 핵심 비교가 됨
