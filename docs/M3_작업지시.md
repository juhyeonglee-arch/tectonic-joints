# M3 레이저 적층 출력 v0.3 (2026-11-17)

세 부재 모서리(다리 + 장선 X + 장선 Y) 두 노드를 판으로 썰어 레이저로 자를 DXF와 조립 순서도로 만든 것.

- **드러냄 노드 (R)**: `node3` 드러냄 후보 1. 장선 X가 다리를 지나 바깥에 끝면이 보이고 장선 Y는 다리 머리에 걸린다. 열쇠는 장선 X (위에서 내려 끼움).
- **숨김 노드 (H)**: `node3` 숨김 후보 1. 다리가 60mm 솟고 장선은 다리 속 장부로만 들어간다. 열쇠는 장선 Y (+y 쪽에서 밀어 끼움). 발견 4대로 장선 Y가 자기 축(+y)으로 다시 빠질 수 있다. 실물에서 확인할 부분이 바로 이것.

## 가정 (실제 값을 받으면 다시 뽑는다)

| 항목 | 가정값 | 바뀌면 |
|---|---|---|
| 판 | 3mm MDF | 실제 두께를 캘리퍼로 10장 재서 평균 → `M3_T` |
| 작업대 | 600×400mm (가장자리 5mm, 부품 간격 3mm) | `M3_BED=600x400` |
| 커프 (레이저 선 폭) | 0.2mm | 시험편 커프 빗으로 재서 `M3_KERF` |
| 맞춤 공차 (부재 사이 틈) | 0.2mm | 시험편 끼움 조각으로 골라 `M3_CLEAR` |
| 정렬 핀 | 지름 4mm 목봉 (구멍은 4.1mm로 설계) | `M3_PIN` |

## 폴더

```
공차시험편/        먼저 자를 것. 공차시험편.dxf + 미리보기
1대1/드러냄_R/     실제 크기. R_판01~11.dxf, 배치_미리보기.png, 판목록.csv, 조립순서도.png
1대1/숨김_H/       실제 크기. H_판01~15.dxf, …
1대2_시험/         절반 크기 (판 두께는 그대로 3mm). 노드마다 작업대 2판이면 끝나서 먼저 싸게 끼워 보기 좋음
적층확인.3dm        판 경계·공차를 반영한 실제로 잘릴 판들을 쌓은 모습 (라이노, 부재별 레이어, 객체 이름 = 판 번호)
출력보고.json       층 경계(설계→판), 판맞춤 전후 검사 결과, 핀 목록
```

## DXF 레이어 (단위 mm)

| 레이어 | 색 | 할 일 | 순서 |
|---|---|---|---|
| ENGRAVE | 파랑(5) | 판 번호 각인 (약한 출력, 선 또는 채움) | 1 |
| CUT_INNER | 자홍(6) | 핀 구멍·속 구멍 자르기 | 2 |
| CUT_OUTER | 빨강(1) | 바깥선 자르기 | 3 |

커프·공차 보정은 **이미 선에 들어가 있다.** 레이저 프로그램(LightBurn 등)에서 커프 오프셋을 또 주지 말 것.

## 순서

1. **공차 시험편** 자르기 → (a) 커프 빗 10조각을 붙여 너비 W를 재면 커프 = (100 − W) / 10. (b) 끼움 조각 1~5를 구멍판의 0.0~0.4 구멍에 끼워 보고, 손으로 꽉 밀어 들어가고 흔들리지 않는 틈을 고른다. (c) 핀 구멍 3.8~4.2 중 목봉이 꽉 끼는 것을 고른다.
2. 값이 가정과 다르면 다시 뽑는다 (아래 명령). 같으면 그대로.
3. **1대2 시험**부터 자르고 끼워 본다 → 그다음 1대1.
4. 부재마다 판을 아래(01)부터 쌓는다. 판끼리만 목공풀로 붙이고, 핀(목봉)에 꿰어 누른 채 굳힌다.
   - 판 번호: `R-L23` = 드러냄 노드, 다리, 아래에서 23째 장. 한 장이 여러 조각이면 `a, b, c`.
   - 글자는 위를 보게 놓고, 글자가 읽히는 방향이 +x(장선 X 쪽)다.
   - 이름 끝에 `T`가 붙은 맨 윗장은 좌우가 뒤집혀 잘려 있다. **글자 면을 아래로** 뒤집어 놓으면 맞는다 (각인이 겉에 안 보이게).
   - 핀은 맨 윗장(장선은 맨 아랫장도)에 구멍을 내지 않았다 (겉에 안 보이게). 그 판은 아래 판 옆면에 직각자를 대고 맞춘다.
   - 핀 길이는 조립순서도 오른쪽 위 목록대로 자른다 (판 수 × 3mm − 1mm).
5. 굳으면 **부재끼리는 붙이지 않고** 조립순서도의 ② 순서대로 끼운다. 헐거움·뻑뻑함·쪼개짐, 열쇠 부재가 다시 빠지는지를 기록한다 (인계 문서 연구 질문 5, 발견 4).

## 판 수

| | 판 장수 (다리/X/Y) | 부품 수 | 작업대 600×400 |
|---|---|---|---|
| 1대1 드러냄 | 80 / 40 / 40 | 240 (다리 판 중 40장이 3조각) | 11판 |
| 1대1 숨김 | 100 / 40 / 40 | 188 | 15판 |
| 1대2 드러냄 | 40 / 20 / 20 | 120 | 2판 |
| 1대2 숨김 | 50 / 20 / 20 | 94 | 2판 |

1대1 두 노드에 600×400 MDF가 26판 든다. 다리 판의 절반(밑동 120mm)은 결구와 상관없는 기둥 밑부분이라, 시험용이면 밑동을 30mm로 줄여 작업대 5판쯤 아낄 수 있다.

## 판 두께로 맞추며 바뀐 것

층 경계가 3mm 배수가 아니면 가장 가까운 배수로 옮겼다 (최대 1.5mm). 옮긴 노드로 검사를 다시 돌렸고 **조립 순서·열쇠 부재·빠지는 방향은 원래와 같다.**
- 드러냄 1대1: 층 경계 185 → 186mm. 구조 점수 116 그대로.
- 숨김 1대1: 145 → 144, 190 → 189mm. 맨 아래 층이 25 → 24mm가 되어 "얇은 층" 감점(−8)을 받아 구조 점수 99.6 → 91.7. 맞물림은 그대로이고, 감점 기준(25mm)에 걸린 것뿐.
- 1대2는 점수 기준(얇은 살 20mm 등)이 실제 크기 기준이라 점수가 낮게 나온다. 맞물림 검사 결과는 1대1과 같다.
